# mac-dotfiles
Private dotfiles for macOS (Apple Silicon).

## Quick start (new machine)

```sh
# 1. Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. Clone + bootstrap
git clone git@github.com:sh-tech-1/dotfiles.git "$HOME/dotfiles"
cd "$HOME/dotfiles"
./bootstrap.sh        # runs defaults.sh → setup.sh → homebrew.sh

# 3. Reload
exec zsh
```

Or run the steps individually (all idempotent / re-runnable):

```sh
./defaults.sh   # macOS system defaults (Finder, key repeat, …)
./setup.sh      # oh-my-zsh, Volta, symlinks, zsh/tmux/vim plugins
./homebrew.sh   # CLI tools + apps
```

## What setup.sh links

| link | target |
|---|---|
| `~/.zshrc` | `.zshrc` |
| `~/.config/nvim/init.vim` | `.vimrc` |
| `~/.tmux.conf` | `.tmux.conf` |
| `~/.procs.toml`, `~/.fdignore` | same names |
| `~/scripts`, `~/original-scripts` | `scripts/`, `original-scripts/` |
| `~/.ssh/config` | `.ssh/config` |

## Machine-specific secrets

`setup.sh` creates an empty `~/.zshrc.local` (git-ignored), sourced at the end of
`.zshrc`. Put tokens / per-host config there:

```sh
export GITHUB_USER=...
export GITHUB_TOKEN=...   # used by login-docker-hub (ldh)
```

Per-host SSH settings go in `~/.ssh/config.local` (also untracked).

## Package management

`homebrew.sh` installs:

- **CLI tools** — an explicit list of formulae the shell config depends on
  (`ripgrep`, `fd`, `bat`, `neovim`, `gnu-sed`, `jq`, `fzf`, `awscli`, …).
- **Apps (casks)** — read from `scripts/.brew_cask_installed`, one token per
  line. This file is the single source of truth: edit it and re-run
  `./homebrew.sh` to add or remove apps.

`scripts/.brew_installed` is a reference snapshot of installed formulae
(regenerated by the `mbi` alias).

## Architecture notes

- `brew` is the **native Apple Silicon** Homebrew (`/opt/homebrew`), wired via
  `brew shellenv`. A Rosetta-launched shell re-execs natively on startup.
- If an Intel Homebrew is also installed under `/usr/local`, reach it with `ibrew`.
